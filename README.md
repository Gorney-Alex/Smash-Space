Description:
A small personal project developed to improve programming skills and explore dependency injection patterns in Unity.

Technologies used:
- Unity Engine 2022.3.9f1
- Zenject for Dependency Injection
- C#
- JSON-based configuration system
- Assembly definition
- UniRX
- MVVM
- UniTask
- WebGLTemplates

To run the project:
1. Open the project in Unity
2. Add the "Menu" scene to the Hierarchy
3. Press Play
